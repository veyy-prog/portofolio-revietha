# portofolio-revietha

## Deskripsi

Website portfolio sederhana yang dibuat sebagai tugas Slicing Website HTML/CSS/JS.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript dengan tampilan yang responsif untuk perangkat desktop maupun mobile.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## Fitur

- Tampilan responsive
- Digital clock
- Tombol perubahan tema
- Navigasi dan interaksi menggunakan JavaScript
- Tampilan portfolio dengan beberapa project
